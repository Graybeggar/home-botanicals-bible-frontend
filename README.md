# Home Botanicals Bible — Frontend

A React single-page app for browsing plants and building a personal garden collection.

## Tech stack

- React 19
- React Router DOM 7
- Vite 7
- ESLint 9

## What it does

- Plant catalog page for browsing plants
- My Garden page for a personal plant collection
- Home, About, Resources, Contact, and Privacy pages
- Shared layout with NavBar and Footer, plus a falling plant-emoji animation on clicks

## How to run

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173). Use `npm run build` to build for production and `npm run preview` to preview the build.
